\chapter{Results}%
\label{ch:results}

In this chapter we show results for our DMFT solver
on the Bethe lattice in infinite dimensions and at half-filling.
We study the Mott metal-to-insulator transition
by continuously varying the Coulomb interaction $U$.
Calculations were done using Julia~\cite{Bezanson2017} version 1.11 and 1.12.
The codebase is contained in two packages:
\texttt{Fermions.jl}~\cite{Wallerberger2022} implements
Hamiltonians, wave functions and their interplay.
The second package \texttt{RAS\_DMFT.jl}\footnote{
    \url{https://github.com/frankebel/RAS_DMFT.jl}
},
which was developed during this work,
contains the DMFT self-consistency loop together
with the representation of correlators and self-energies.
A tutorial of the latter is available in \zcref{app:code-tutorial}.

For all following calculations we set the half-bandwidth $D=1$ as our unit of energy.
For the discretization of our hybridization function $\Delta_\omega$
we use an odd number of bath sites $N$
with $(N - 1)/2$ poles on the positive and negative axis respectively
and one pole at exactly zero.
The locations of these poles $\{\epsilon_i\}$ are fixed at the beginning
and kept between each DMFT cycle.
This is in contrast to~\cite{Lu2014, Lu2019} where the locations could shift in each iteration.
If, in the DMFT update (\zcref{eq:hybridization-update}), we get a pole $\epsilon$ which is not on the given grid,
we shift its weight such that the zeroth and first moment are locally conserved.
This scheme is explained in \zcref{app:shifting-of-poles}.
The poles of correlators and self-energies are not put onto this predefined grid.
Before the first DMFT step,
the continuous hybridization function is discretized on the aforementioned locations
with weights
\begin{equation}
    V_i^2 = -\frac{1}{\muppi} \int_{I_i} \md\omega\> \Im \Delta_{0,\omega}.
\end{equation}
The interval endpoints are chosen to be halfway between neighboring bath energies
\begin{equation}
    I_i = \left[\frac{\epsilon_{i-1} + \epsilon_i}{2}, \frac{\epsilon_i + \epsilon_{i+1}}{2}\right].
\end{equation}
The lower bound for the first point is set to $-\infty$
while the upper bound for the last point is $+\infty$.
This asserts that
the sum of all discrete weights equals the zeroth moment of the continuous function\footnote{
    The zeroth moment is conserved exactly while higher moments are not.
    The higher the moment,
    the more it differs between the discrete and continuous one.
    Odd moments stay zero as the discrete function is still symmetric.
}.
The following DMFT self-consistency calculations were done on $N=301$ bath sites
and a Krylov space $M=200$ to be comparable to~\cite{Lu2019}.
(Each block Lanczos step produces two poles which is equivalent to $M=400$ for scalar Lanczos.)

\section{Ground state convergence}

Before we can calculate any correlators or expectation values,
we first need to find the ground state of our system.
The hybridization function,
is discretized on $N=101$ equidistant bath sites in the interval $[-D, D]$.
Given the parameters $\{\epsilon_i, V_i\}$,
we can create $H_\mathrm{bath}$ and $H_\mathrm{imp-bath}$ of
\zcref{eq:H-Anderson-bath, eq:H-Anderson-impurity-bath}.
For the impurity $H_\mathrm{imp}$ we then add a Coulomb interaction of $U=2D$ which fixes our
on-site energy to $\epsilon=-D$, $\mu=0$ for half-filling, only nearest-neighbor hopping.
We can then iteratively find our ground state using the algorithm described in \zcref{sec:ground-state}.
The variance after each restart is shown in \zcref{fig:ground-state-convergence}.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/ground_state_convergence.tex}
    \caption{
        Krylov space convergence:
        Variance of the Hamiltonian on a state $\ket{\psi}$
        calculated by the Lanczos algorithm from \zcref{sec:ground-state}.
        For the ground state the variance must vanish.
        The dashed line indicates double precision machine epsilon $2^{-52}$.
    }%
    \label{fig:ground-state-convergence}
\end{figure}
We see that it decreases exponentially with the number of restarts and reaches
below double precision $\epsilon_\mathrm{MP} = 2^{-52}$.
Although not shown,
this is also the case for other values of $U$.
In general, the bigger the explored Hilbert space
(increasing the exact system size $L$
and allowed excitations $p$ in the remaining chains),
the more steps are necessary to reach a desired variance.
For the parameters $L=1$, $p=1$, machine precision is reached after \num{16} iterations
which equals a Krylov size\footnote{
    Each restart explores a further space of $\mathcal{K}^5$.
}
of $M=80$,
while for higher parameters $L$, $p$ more steps are necessary for a desired variance.
To fully propagate an electron (hole) excitation through the conduction (valence) band,
one should at least explore a space of $M=N/2$ where $N/2$ is the length of a chain.
For our choice of $N=101$ this corresponds to $M=50$ which is fulfilled for all cases.
In \zcref{tab:ground-state-energy} we list the ground state energy $E_0$ obtained in the
calculation of \zcref{fig:ground-state-convergence}.

As expected, the energy is lower if the explored Hilbert space is larger.

\section{Performance analysis}

To obtain our correlators listed in \zcref{eq:correlators},
we have to calculate a block tridiagonal matrix $T$
using the block Lanczos algorithm explained in \zcref{sec:block-lanczos}.
As this is the most time-consuming part within the DMFT step,
we benchmarked its time and memory requirements in \zcref{fig:performance}.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/performance.tex}
    \caption{
        Runtime and total memory allocations
        to obtain the block correlator on the positive real axis $C^+_\omega$ using
        the block Lanczos algorithm described in \zcref{sec:block-lanczos}.
        Given the ground state, the benchmarked task is to create the vectors
        $\tilde q^\dag_\sigma\ket{\psi_0}$
        and
        $d^\dag_\sigma\ket{\psi_0}$ as our input.
        In \subref{subfig:perf-time-krylov},
        \subref{subfig:perf-allocations-krylov}
        we fix the number of bath sites to $N=161$.
        In \subref{subfig:perf-time-sites},
        \subref{subfig:perf-allocations-sites}
        we fix the number of Krylov steps to $M=160$.
    }%
    \label{fig:performance}
\end{figure}
For each data point we ran the same calculation ten times and show the minimum
as our estimator~\cite{Chen2016}.
The operations were done on an AMD EPYC\texttrademark~9654 processor
with 96 cores and \qty{1}{\tera\byte} of memory,
but can also be run on consumer hardware.
Although the code is multithreaded,
the benchmarks were run on a single thread for easier reproducibility.
Given the ground state, we create the excited states
$\tilde q^\dag_\sigma\ket{\psi_0}$
and
$d^\dag_\sigma\ket{\psi_0}$ as our block Lanczos input allowing us to calculate
the partial correlator $C^+_\omega$ on the positive real axis.
In \zcref{subfig:perf-time-krylov},
we fixed the number of bath sites to $N=161$.
We see that the runtime is linear with the number of Krylov steps $M$.
This is expected as our wave function representation stores determinants
in the restricted part $\ket{\psi_\mII}$ in a dense format.
As all possible states are already present in the first step,
each subsequent Lanczos iteration takes the same amount of time
resulting in a linear scaling.
\zcref{subfig:perf-allocations-krylov} shows the used memory during calculations.
We see an almost constant behavior.
This is because the Lanczos algorithm only needs the last two states for
orthogonalization.
Thus, we can overwrite the oldest state in-place in each iteration.
However, there are still some allocations of the order \qty{10}{\mega\byte}
coming from matrix diagonalization and matrix multiplication.
These allocations are negligible on current hardware
which has multiple \unit{\giga\byte} of memory.

In \zcref{subfig:perf-time-sites}
we analyze the time required for a fixed number of Krylov steps $M=160$ by varying
the number of bath sites $N$.
For the restricted excitation,
the number of possible states is
\begin{equation}
    \binom{2(N-1-2L)}{p},
\end{equation}
where the factor 2 accounts for two spin states at each site,
and the reduction of sites results from only looking at part of the chains.
For $N \gg L$ and $N \gg p$ (we are using $L, p\in\{1,2\}$),
the scaling of the binomial coefficient can be written as $N^p$.
Thus, for $p=1$ we see a linear scaling with increased bath sites while for $p=2$ it is quadratic.
We also see that raising the parameter $L$ (the number of chain sites treated exactly)
by one increases the complexity by a factor of more than ten.
A calculation of all possible states\footnote{
    The exact number depends on the values of $N$ and $p$ too.
    For the relevant regime the complexity by increasing $L$ by one unit varies between 12 and 14.
    To emphasize the worst scaling, we take the value of 14 in the main text.
    Full details are available in \zcref{app:number-slater-determinants}.
}
reveals a ratio of around 14 which is relatively close to the measured one.
\zcref{subfig:perf-allocations-sites} shows the required memory for those calculations
which scales as $N$ and $N^2$, too.

In summary, we can say that our computational complexity scales approximately as $\bigO{14^L M N^p}$
while memory complexity scales as $\bigO{14^L N^p}$.

\section{Correlators}

For the following calculations we first define $N=301$ equidistant poles
$\{\epsilon_i\}$ in the interval $[-4D, 4D]$
and discretize the non-interacting hybridization function $\Delta_{0,\omega}$ on them.
Poles outside $[-D, D]$ have zero weight.
Thus, our non-interacting hybridization has 75 non-vanishing poles.
We then repeat our DMFT loop which calculates a new hybridization function $\Delta_\omega$
in each step until self-consistency is reached.
As the self-energy pushes spectral weight to higher frequencies,
poles which initially had zero weight obtain a finite value.
The explored Hilbert space is restricted to $L=2$, $p=2$.
In \zcref{fig:correlators-metal} we list the real and imaginary parts
of our block correlator $C_\omega$ for a metallic solution $U/D=2$.

\section{Spectral function}

We again emphasize that the self-consistency calculation uses no-broadening,
which is only introduced as a post-processing step to plot smooth spectra instead of discrete peaks.
Numerically we never get a pole at exactly zero which is why strictly speaking,
all of our solutions are insulating.
For a $p=1$ projection (not shown) we observe spurious oscillations on the Hubbard bands,
consistent with~\cite{Lu2019}.
These are supressed if we increase the Hilbert space to $p=2$,
as shown in \zcref{fig:spectral-function} for $L=2$.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/spectra.tex}
    \caption{
        DMFT impurity spectral function $A_\omega$ for the half-filled Bethe lattice.
        \subref{subfig:spectrum-U1.0},
        \subref{subfig:spectrum-U2.0},
        \subref{subfig:spectrum-U2.4}
        show the evolution of the Hubbard bands and Kondo peak
        with increasing interaction strength $U$.
        \subref{subfig:spectrum-U4.0} shows an insulating solution where the bands are
        fully disconnected.
        For each value of $U$,
        we plot the same data using a
        Lorentzian ($\delta/D=0.04$),
        Gaussian ($\sigma/D=0.04$),
        and logarithmic Gaussian ($b/D=0.6$)
        broadening.
    }%
    \label{fig:spectral-function}
\end{figure}
For each fixed value of the Coulomb interaction $U$,
we plot the same data using a
Lorentzian ($\delta/D=0.04$),
Gaussian ($\sigma/D=0.04$),
and logarithmic Gaussian ($b/D=0.6$)
broadening.
As we do not get our poles on a logarithmic grid,
the latter had to be truncated at a rather large value of $\omega/D=\num{5e-2}$
to generate smooth spectra\footnote{
    Therefore,
    in the interval $\omega/D\in[-\num{5e-2}, \num{5e-2}]$ the spectrum is set to a constant value.
}.
At small interaction \zcref{subfig:spectrum-U1.0}
we see the beginning of the Hubbard band formation.
We see a small dip at the Fermi-energy,
as there are no poles very close to it.
This is in contrast to NRG~\cite{Bulla2008} which is tailored to impurity problems by utilizing
a logarithmic grid.
If we increase the interaction \zcref{subfig:spectrum-U2.0},
we can see fully formed Hubbard bands and the central Kondo peak.
At $U/D=2.4$ in \zcref{subfig:spectrum-U2.4}, we see small peaks in the
inner edge of the Hubbard band,
consistent with previous results~\cite{Karski2005,Karski2008,Zitko2009,Gull2010,Granath2012,Granath2014,Ganahl2014,Lu2014,Lu2019,Lee2017}.
In \zcref{subfig:spectrum-U4.0} we show an insulating solution;
The bands are fully separated and peaked at approximately $\pm U/2$.
The shape is approximately the non-interacting semicircular density.
As the Lorentzian broadening decays slowly,
there is still some weight left at the Fermi-energy.

As the imaginary part of the self-energy vanishes at the Fermi-energy
for zero temperature~\cite{Hewson1993},
any \emph{metallic} spectral function must have the same value as the non-interacting one.
This forces the pinning of the Kondo peak to a height of $\muppi D A(\omega=0) = 2.0$.
We see that this is well fulfilled for the top two panels using Gaussian broadening,
while in \zcref{subfig:spectrum-U2.4} this is slowly lost.
In general, for the chosen parameters the Gaussian broadening shows all features
well while the logarithmic broadening smears out too much at higher energies.
This may be mitigated by using more advanced broadening schemes~\cite{Lee2016}.

The DMFT calculation was also tried using a logarithmic grid
with pole locations fixed to have equal ratio
$\epsilon_{i+1}/\epsilon_i = \Lambda=1.075$~\cite{Bulla2008} and
the outermost pole located at $\epsilon_N = 4D$.
The Kondo peak and pinning condition were marginally improved while
the Hubbard bands showed discretization artifacts under the same broadening parameters.

In \zcref{tab:spectrum-moments} we compare the moments of our Green's function
against the exact ones from \zcref{eq:spectrum-moments}.
The zeroth moment matches up to numerical precision $\bigO{\epsilon_\mathrm{MP}}$
while higher moments differ around $\bigO{\sqrt{\epsilon_\mathrm{MP}}}$.
This is in contrast to NRG~\cite{Bulla2008,Kugler2022} which only conserves the lowest order
while higher ones are less accurate.
We also see no inherent bias in the data as we both over- and underestimate the exact values.

\section{Mott transition}%
\label{sec:Mott-transistion}

As shown in the previous sections,
depending on the interaction strength $U$ we can get a metallic or insulating solution.
Here, we want to quantify this transition.
If one starts from a metallic solution,
the transition to an insulator is of second order~\cite{Georges1996}.
The ground state energy (which is lower for  a metal) smoothly approaches that of an insulator
and coincides at the critical value $U_{c2}$.
In contrast, the transition of an insulator to metal is of first order~\cite{Georges1996}
with a metastable solution which abruptly jumps at a critical value $U_{c1}$.
In the coexistence region $U_{c1} \le U \le U_{c2}$ it is possible to find both solutions.

One way of quantifying this region is to use the double occupation $\expval{n_\uparrow n_\downarrow}$,
which is the ground state probability of finding both a spin-up and spin-down electron
in the impurity.
The results are shown in \zcref{fig:double-occupation}.
For a non-interacting system ($U=0$) $\expval{n_\uparrow n_\downarrow}=0.25$,
and it gets lower with increasing interaction strength.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/double_occupation.tex}
    \caption{
        Double occupation $\expval{n_\uparrow n_\downarrow}$
        on the ground state as a function of $U$.
        The discretization of the hybridization function was varied between methods.
        \subref{subfig:double-occupation} Comparison against NRG data~\cite{Gauvin-Ndiaye2025}.
        \subref{subfig:double-occupation-zoom}
        Zoom-in close to the metal-insulator transition.
    }%
    \label{fig:double-occupation}
\end{figure}
In \zcref{subfig:double-occupation} we see that our solver has very good agreement with
NRG data~\cite{Gauvin-Ndiaye2025} for weak to intermediate interaction strengths.
In \zcref{subfig:double-occupation-zoom} we look at the transition using different discretization
schemes of the hybridization function.
(The broadening of spectra is zero.)
In the linear and logarithmic discretization, the poles $\{\epsilon_i\}$ of the hybridization function
are at fixed locations.
For the former they are equidistant,
while in the latter they are apart at a constant ratio $\epsilon_{i+1}/\epsilon_i = \Lambda$.
In the equal weight discretization,
the weights $\{V_i\}$ are set to be equal~\cite{Lu2019}
while pole locations vary between each DMFT step.
We see that up until $U/D\approx2.5$ the double occupation is independent of the discretization.
However, the value $U$ where it equals the insulating solution of NRG differs.
The logarithmic discretization becomes insulating at a value $U_{c2}/D\approx3.2$,
while for the linear and equal weight discretization it is around $U_{c2}/D\approx3.3$.
All of these values somewhat overshoot the NRG value of $U_{c2}/D=2.94$~\cite{Bulla1999}.

Using our method,
it was not possible to find a metastable insulating solution.
For any value $U<U_{c2}$, the solution immediately jumped to a metallic one.
Thus, we cannot make any statement about $U_{c1}$.

Another way to find the value of $U_{c2}$ is to look at the quasiparticle weight $Z$ and see
where it vanishes, corresponding to a diverging quasiparticle mass $m^*\to\infty$.
To obtain it,
we use equation~\zcref{eq:quasiparticle-weight} which diverges for a pole located at zero.
The problem is that our Green's functions are numerically always insulating,
and the self-energy always contains this problematic pole.
E.g., for $U=1$, we have a pole
\begin{equation}
    \frac{\num{9.39e-10}}{\omega + \mi0^+ + \num{5.94e-9}}
\end{equation}
which is not visible in the spectrum.
However,
if one tries to calculate the quasiparticle weight it results in
\begin{equation}
    Z
    =
    \left(1 + \frac{\num{9.39e-10}}{(\num{5.94e-9})^2}\right)^{-1}
    =
    (\num{2.67e7})^{-1}
    \approx
    0.
\end{equation}
Hence, we have to neglect poles with weights $<\num{3e-5}$
in the calculation of \zcref{eq:quasiparticle-weight}.
In \zcref{subfig:quasiparticle-weight} our quasiparticle weight is higher than the NRG data,
similar to~\cite{Karski2005, Karski2008} where a D-DMRG solver was used.

In \zcref{subfig:quasiparticle-weight-zoom} we look at the transition
using the same discretization schemes as in the double occupation.
We see the same behavior:
The logarithmic discretization becoming
insulating first followed by the linear and equal weight discretization.

In~\cite{Karski2005, Karski2008},
computed data in the interval $U/D\in[2.0,2.8]$
was used to fit a quadratic function
\begin{equation}
    f_Z(U) = a_1(U - U_{c2}) + a_2(U - U_{c2})^2.
\end{equation}
If we fit our data using the same interval,
we get the lines shown in \zcref{subfig:quasiparticle-weight-zoom}.
Our logarithmic discretization now becomes metallic at $U_{c2}/D=3$
closely followed by the linear discretization.
The equal weight one becomes insulating at $U_{c2}/D=3.1$.
We attribute this difference of the fit against the measured data points
in $U/D\in(2.8,3.4]$ as discretization artifacts % chktex 9
stemming from the fact that we do not have enough poles close to the Fermi-level,
in contrast to NRG\@.

\section{\texorpdfstring{CeRu$_4$Sn$_6$}{CeRu4Sn6}}

Here, we briefly test our code for the material
CeRu$_4$Sn$_6$~\cite{Sundermann2015, Wissgott2016, Dobilas2025}.
The Ce-$f$ orbital is in a partially filled state giving rise to strong electronic correlations.
We created a one-orbital Hubbard model with
interaction strength $U=\qty{5.5}{\eV}$~\cite{Wissgott2016}.
During the DMFT steps we used a Lorentzian broadening of $\delta=\qty{0.04}{\eV}$
as the method of calcualting the self-energy using
the Schur complement (\zcref{eq:self-energy-schur}) without broadening was
not implemented at this time.

In \zcref{fig:spectral-function-CeRu4Sn6} we plot the resulting spectral function
which has the classical three-peak structure with lower and upper Hubbard bands
and a central Kondo peak.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/spectrum_CeRu4Sn6.tex}
    \caption{
        DMFT impurity spectral function for the one-orbital model of CeRu$_4$Sn$_6$.
    }%
    \label{fig:spectral-function-CeRu4Sn6}
\end{figure}
As the system is not half-filled,
the locations and structure of the Hubbard bands are not mirrors of each other.
At zero temperature, the Kondo peak must be at the Fermi-level,
which is the case for our calculation.
However,
due to the finite value of $\delta$, its height is much smaller than anticipated.
This may be improved by using the method with zero broadening instead. % chktex 17
