\chapter{Results}

In this chapter we show results for our DMFT solver.
The calculations were done using Julia~\cite{Bezanson2017} version 1.11 and 1.12.
The codebase is contained in two packages:
\texttt{Fermions.jl}~\cite{Wallerberger2022} implements
Hamiltonians, wave functions and their interplay.
The second package \texttt{DMFT.jl}\footnote{
    \url{https://github.com/frankebel/DMFT.jl}
}
\fe{
    Should it be moved to the organization \url{https://github.com/tuwien-cms}?
    I'm not part of the organization and don't have permissions.
    Also, should we try to find a better package name?
}
contains the DMFT self-consistency loop together
with the representation of correlators and self-energies.

For all following calculations we set the half-bandwidth $D=1$ as our unit of energy.
For the discretization of our hybridization function $\Delta_\omega$
we use an odd number of bath sites $N$
with $(N - 1)/2$ poles on the positive and negative axis respectively
and one pole at exactly zero.
The locations of these poles $\{\epsilon_i\}$ are fixed at the beginning
and kept between each DMFT cycle.
This is in contrast to~\cite{Lu2014, Lu2019} where the locations could shift in each iteration.
If, in the DMFT update (\zcref{eq:hybridization-update}), we get a pole $\epsilon$ which is not on the given grid,
we shift its weight to nearest neighbors,
locally conserving the zeroth and first moment.
This scheme is explained in \zcref{app:shifting-of-poles}.
In the first step, the continuous function is discretized on the aforementioned locations
with hybridization weights
\begin{equation}
    V_i^2 = -\frac{1}{\muppi} \int_{I_i} \md\omega\> \Im \Delta_{0,\omega}.
\end{equation}
The interval endpoints are chosen to be halfway between neighbors
\begin{equation}
    I_i = \left[\frac{\epsilon_{i-1} + \epsilon_i}{2}, \frac{\epsilon_i + \epsilon_{i+1}}{2}\right].
\end{equation}
The lower bound for the first point is set to $-\infty$
while the upper bound for the last point is $+\infty$.
This asserts that
the sum of all discrete weights equals the zeroth moment of the continuous function\footnote{
    The zeroth moment is conserved exactly while higher moments are not.
    The higher the moment,
    the more it differs between the discrete and continuous one.
    Odd moments stay zero as the discrete function is still symmetric.
}.
The following DMFT self-consistency calcualtions were done on $N=301$ bath sites
and a Krylov space $M=200$ to be comparable to~\cite{Lu2019}.
(Each block Lanczos step produces two poles which is equivalent to $M=400$ for scalar Lanczos.)

\section{Ground state convergence}

Before we can calculate any correlators or expectation values,
we first need to find the ground state of our system.
To get a discrete hybridization function,
we create $N=101$ equidistant bath sites in the interval $[-D, D]$ and
discretize our semicircular DOS\footnote{
    We need to multiply it by $D^2/4$ as dictated by \zcref{eq:hybridization-function-bethe}.
}
(\zcref{eq:dos-semicircle}) onto these points.
Given the parameters $\{\epsilon_i, V_i\}$,
we can create $H_\mathrm{bath}$ and $H_\mathrm{imp-bath}$ of \zcref{eq:H-Anderson}.
For the impurity $H_\mathrm{imp}$ we then add a Coulomb interaction of $U=2D$ which fixes our
on-site energy to $\epsilon-\mu=-D$ for half-filling.
We can then iteratively find our ground state using the algorithm described in \zcref{sec:ground-state}.
The variance after each restart is shown in \zcref{fig:ground-state-convergence}.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/ground_state_convergence.tex}
    \caption{
        Variance of the Hamiltonian on a state $\ket{\psi}$
        calculated by the algorithm from \zcref{sec:ground-state}.
        For the ground state the variance must vanish.
        The dashed line indicates double precision machine epsilon $2^{-52}$.
    }%
    \label{fig:ground-state-convergence}
\end{figure}
We see that it decreases exponentially with the number of restarts and reaches
below double precision machine precision $\epsilon_\mathrm{MP} = 2^{-52}$.
Although not shown,
this is also the case for other values of $U$.
In general, the bigger the explored Hilbert space
(increasing the exact system size by the parameter $L$
and increasing the allowed excitations $p$),
the more steps are necessary to reach a desired variance.
For the parameters $L=1$, $p=1$, machine precision is reached after \num{16} restarts
which equals a Krylov size\footnote{
    Each restart explores a further space of $\mathcal{K}^5$.
}
of $M=80$,
while for higher parameters $L$, $p$ more steps are necessary for a desired variance.
To fully propagate an electron (hole) excitation through the conduction (valence) band,
one should at least explore a space of $M=N/2$ where $N/2$ is the
approximate length of a chain.
For our choice of $N=101$ this corresponds to $M=50$ which is fulfilled for all cases.
In \zcref{tab:ground-state-energy} we list the ground state energy $E_0$ obtained in the
calculation of \zcref{fig:ground-state-convergence}.
\begin{table}[ht]

        on 101 bath sites for parameters $L$, $p$.
        The energy difference is less than one per mille of the half-bandwidth $D$.
    }%
    \label{tab:ground-state-energy}
    \centering
    \pgfplotstabletypeset[
        columns/L/.style={
                column name=$L$,
            },

            },

\end{table}
We see that the values are very close to each other with an absolute difference
of less than one per mille of the bandwidth.
As expected, the energy is lower if the explored Hilbert space is larger.

\section{Performance analysis}

To obtain our correlators listed in \zcref{eq:correlators},
we have to calculate the block tridiagonal matrix $T$
using the block Lanczos algorithm explained in \zcref{sec:block-lanczos}.
As this is the most time-consuming part within the DMFT step,
we benchmarked its time and memory requirements in \zcref{fig:performance}.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/performance.tex}
    \caption{
        Runtime and memory allocations
        to obtain the block correlator on the positive real axis $C^+_\omega$ using
        the block Lanczos algorithm described in \zcref{sec:block-lanczos}.
        Given the ground state, we create the vectors
        $\tilde q^\dag_\sigma\ket{\psi_0}$
        and
        $d^\dag_\sigma\ket{\psi_0}$ as our input.
        In \subref{subfig:perf-time-krylov},
        \subref{subfig:perf-allocations-krylov}
        we fix the number of bath sites to $N=161$.
        In \subref{subfig:perf-time-sites},
        \subref{subfig:perf-allocations-sites}
        we fix the number of Krylov steps to $M=160$.
    }%
    \label{fig:performance}
\end{figure}
For each data point we ran the same calculation ten times and show the minimum
as our estimator~\cite{Chen2016}.
The operations were done on an AMD EPYC\texttrademark~9654 processor
with 96 cores and \qty{1}{\tera\byte} of memory,
but can also be run on consumer hardware.
Although the code is multithreaded,
the benchmarks were run on one thread for easier reproducibility.
Given the ground state, we create the excited states
$\tilde q^\dag_\sigma\ket{\psi_0}$
and
$d^\dag_\sigma\ket{\psi_0}$ as our block Lanczos input allowing us to calculate
the partial correlator $C^+_\omega$ on the positive real axis.
In \zcref{subfig:perf-time-krylov},
we fixed the number of bath sites to $N=161$.
We see that the runtime is linear with the number of Krylov steps $M$.
This is expected as our wave function representation stores determinants
in the restricted part $\ket{\psi_\mathrm{II}}$ in a dense format.
As all possible states are already present in the first step,
each subsequent Lanczos iteration takes the same amount of time
resulting in a linear scaling.
\zcref{subfig:perf-allocations-krylov} shows the used memory during calculations.
We see an almost constant behavior.
This is because the Lanczos algorithm only needs the last two states for
orthogonalization.
Thus, we can overwrite the oldest state in-place in each iteration.
However, there are still some allocations of the order \qty{10}{\mega\byte}
coming from matrix diagonalization and matrix multiplication.
These allocations are negligible on current hardware
which has multiple \unit{\giga\byte} of memory.

In \zcref{subfig:perf-time-sites}
we analyze the time taken for a fixed number of Krylov steps $M=160$ by varying
the number of bath sites $N$.
For the restricted excitation,
the number of possible states is
\begin{equation}
    \binom{2(N-1-2L)}{p},
\end{equation}
where the factor 2 accounts for two spin states at each site,
and the reduction of sites results from only looking at part of the chains.
For $N \gg L$ and $N \gg p$ (we are using $L, p\in\{1,2\}$),
the scaling of the binomial coefficient can be written as $N^p$.
Thus, for $p=1$ we see a linear scaling with increased bath sites while for $p=2$ it is quadratic.
We also see that raising the parameter $L$ (the number of chain sites treated exactly)
by one increases the complexity by a factor of more than ten.
A calculation of all possible states\footnote{
    The exact number depends on the values of $N$ and $p$ too.
    For the relevant regime the complexity by increasing $L$ by one unit varies between 12 and 14.
}
reveals a ratio of around 14 which is relatively close to the measured one.
\zcref{subfig:perf-allocations-sites} shows the required memory for those calculations
which scales as $N$ and $N^2$ respectively.

In summary, we can say that our computational complexity scales approximately as $\bigO{14^L M N^p}$
while memory complexity scales as $\bigO{14^L N^p}$.

\section{Correlators}

For the following calculations we first define $N=301$ equidistant poles
$\{\epsilon_i\}$ in the interval $[-4D, 4D]$
and discretize the non-interacting hybridization function $\Delta_{0,\omega}$ on them.
Poles outside $[-D, D]$ are discarded as they have zero weight.
Thus, our non-interacting hybridization is made out of 75 poles.
We then repeat our DMFT loop until self-consistency is reached.
The explored Hilbert space is restricted to $L=2$, $p=2$.
In \zcref{fig:correlators-metal} we list the real and imaginary parts
of our block correlator $C_\omega$ for a metallic solution $U=2D$.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/correlators_metal.tex}
    \caption{
        Components of the $2\times2$ block correlator $C(\omega)$ for
        a Coulomb interaction of $U=2D$ (metallic solution).
        Peaks are broadened with a Gaussian kernel $\sigma=0.04D$.
        At half-filling, the spectral part (imaginary part) of
        \subref{subfig:correaltor-I-metal} and \subref{subfig:correaltor-G-metal}
        are symmetric.
        Due to the shift of \zcref{eq:shift}, the spectra of
        \subref{subfig:correaltor-FL-metal} and \subref{subfig:correaltor-FR-metal}
        are antisymmetric.
    }%
    \label{fig:correlators-metal}
\end{figure}
Each discrete pole was broadened with a Gaussian kernel $\sigma=0.04D$.
We see that the spectra of the diagonal entries
\zcref{subfig:correaltor-I-metal, subfig:correaltor-G-metal} are symmetric
due to particle-hole symmetry.
The imaginary part is negative (the spectrum positive semidefinite)
as the weight $w_i$ of each pole is positive.
The spectra of the offdiagonal entries
\zcref{subfig:correaltor-FL-metal, subfig:correaltor-FR-metal}
are antisymmetric due the shift in \zcref{eq:shift}.
As we use real-valued amplitudes,
the condition $F^\mR_\omega = (F^\mL_\omega)^\dag$ simplifies to
$F^\mR_\omega = F^\mL_\omega$.
Using these symmetries,
it is possible to only calculate $C^+_\omega$ and mirror the entries for $C^-_\omega$
with an appropriate sign flip.
This was deliberately not done in this work to show that symmetry is conserved even numerically.

In \zcref{fig:correlators-insulator} we show the same quantities
for an insulating solution $U=4.0D$.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/correlators_insulator.tex}
    \caption{

\end{figure}
The symmetry arguments are the same.
In contrast to the metallic solution however,
none of the spectra show any weight at the Fermi-energy.

\section{Spectral function and moments}

We again emphasize that the self-consistency calculation uses no-broadening,
which is only introduced as a post-processing step to plot smooth spectra instead of discrete peaks.
For a $p=1$ projection (not shown) we observe spurious oscillations on the Hubbard bands,
consistent with~\cite{Lu2019}.
These are supressed if we increase the Hilbert space to $p=2$,
as shown in \zcref{fig:spectral-function} for $L=2$.
\begin{figure}[ht]
    \centering
    \input{graphics/tikz/spectra.tex}
    \caption{
        DMFT impurity spectral function for the half-filled Bethe lattice.
        \subref{subfig:spectrum-U1.0},
        \subref{subfig:spectrum-U2.0},
        \subref{subfig:spectrum-U2.4}
        show the evolution of the Hubbard bands and Kondo peak
        with increasing interaction strength $U$.
        \subref{subfig:spectrum-U4.0} shows an insulating solution where the bands are
        fully disconnected.
        For each value of $U$,
        we plot the same data using a
        Lorentzian ($\delta/D=0.04$),
        Gaussian ($\sigma/D=0.04$),
        and logarithmic Gaussian ($b/D=0.6$)
        broadening.
    }%
    \label{fig:spectral-function}
\end{figure}
For each fixed value of the Coulomb interaction $U$,
we plot the same data using a
Lorentzian ($\delta/D=0.04$),
Gaussian ($\sigma/D=0.04$),
and logarithmic Gaussian ($b/D=0.6$)
broadening.
As we do not get our poles on a logarithmic grid,
the latter had to be truncated at a rather large value to generate smooth spectra.
At small interaction \zcref{subfig:spectrum-U1.0}
we see the beginning of the Hubbard band formation.
We see a small dip at the Fermi-energy,
as there are no poles very close to it.
This is in contrast to NRG~\cite{Bulla2008} which is tailored to impurity problems by utilizing
a logarithmic grid.
If we increase the interaction \zcref{subfig:spectrum-U2.0},
we can see fully formed Hubbard bands and the central Kondo peak.
At $U/D=2.4$ in \zcref{subfig:spectrum-U2.4}, we see small peaks in the
inner edge of the Hubbard band,
consistent with previous results~\cite{Karski2005,Karski2008,Zitko2009,Gull2010,Granath2012,Granath2014,Ganahl2014,Lu2014,Lu2019,Lee2017}.
In \zcref{subfig:spectrum-U4.0} we show an insulating soltuion;
The bands are fully separated and peaked at approximately $\pm U/2$.
The shape is approximately the non-interacting semicircular density.
As the Lorentzian broadening decays slowly,
there is still some weight left at the Fermi-energy.

As the imaginary part of the self-energy vanishes at the Fermi-energy
for zero temperature~\cite{Hewson1993},
any metallic spectral function must have the same value as the non-interacting one.
This forces the pinning the Kondo peak to a height of $\muppi D A(\omega=0) = 2.0$.
We see that this is well fulfilled for the top two panels,
while in \zcref{subfig:spectrum-U2.4} this is slowly lost.
In general, for the chosen parameters the Gaussian broadening shows all features
well while the logarithmic broadening smears out too much at higher energies.
This may be mitigated by using more advanced broadening schemes~\cite{Lee2016}.

The DMFT calculation was also tried using a logarithmic grid
with pole locations fixed to have equal ratio $\Lambda=1.075$~\cite{Bulla2008} and
the outermost pole located at $4D$.
The Kondo peak and pinning condition were marginally improved while
the Hubbard bands showed discretization artifacts if the same broadening parameters were used.

against the exact ones from \zcref{eq:spectrum-moments}.

The zeroth moment matches up to numerical precision $\bigO{\epsilon_\mathrm{MP}}$

This is in contrast to NRG~\cite{Bulla2008,Kugler2022} which only conserves the lowest order
while higher ones are less accurate.
As we both over- and underestimate the exact values,
we assume that our error is of stochastic nature.
